## Catatan

Apabila GitHub menampilkan pesan "Invalid Notebook" saat melakukan pratinjau file notebook (.ipynb), silakan unduh file tersebut dan buka menggunakan Google Colab. Notebook telah diuji dan dapat dibuka dengan baik, serta seluruh kode, output, dan hasil analisis dapat ditampilkan secara normal di Google Colab.

Pesan tersebut muncul karena keterbatasan GitHub dalam merender metadata tertentu yang dihasilkan oleh Google Colab dan tidak memengaruhi isi maupun fungsionalitas notebook.

## Note

If GitHub displays an "Invalid Notebook" message when previewing a notebook file (.ipynb), please download the notebook and open it using Google Colab. The notebook has been tested and can be opened successfully, with all code cells, outputs, and results displayed correctly in Google Colab.

The issue is related to GitHub's notebook renderer and does not affect the functionality or contents of the notebook.
